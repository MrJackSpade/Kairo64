# Google Play listing: Japanese (ja-JP)

- **App name:** Kairo64

## Short description

Android で、お手持ちの C64 ゲームをタッチ操作やゲームパッドで遊べます。

## Full description

Kairo64 は、お手持ちの C64 ゲームを Android で遊べるアプリです。ディスク、テープ、プログラム、カートリッジのイメージを追加してライブラリからゲームを選び、ゲームパッドまたは画面上のコントロール（C64 キーボードを含む）で遊べます。2 画面の携帯ゲーム機では、ゲームとコントロールを別々の画面に表示できます。

ゲームは含まれていません。ほとんどのゲームは同梱の MEGA65 Open ROMs で動作しますが、一部のゲームにはお手持ちの実機の Commodore 純正ファームウェアが必要です。

同じアプリを Kairo64 の GitHub Releases から無料でダウンロードすることもできます。Play 版にも同じ機能があります。

Kairo64 は、VICE と MEGA65 Open ROMs を使った独立したプロジェクトです。
