# Google Play listing: Russian (ru-RU)

- **App name:** Kairo64

## Short description

Играйте в игры для C64 на Android с сенсорным управлением или геймпадом.

## Full description

Kairo64 позволяет играть в ваши собственные игры для C64 на Android. Добавьте свои образы дисков, кассет, программ или картриджей, выберите игру в библиотеке и играйте с геймпадом или с экранным управлением, включая клавиатуру C64. На портативных устройствах с двумя экранами игру и управление можно вывести на разные экраны.

Игры не входят в комплект. Большинство игр работают с прилагаемыми MEGA65 Open ROMs; некоторым нужна оригинальная прошивка Commodore с вашего собственного компьютера.

Это же приложение можно бесплатно скачать в GitHub Releases Kairo64. В версии из Google Play те же возможности.

Kairo64 — независимый проект на основе VICE и MEGA65 Open ROMs.
