# Google Play listing: Indonesian (id)

- **App name:** Kairo64

## Short description

Mainkan game C64 Anda di Android dengan kontrol sentuh atau gamepad.

## Full description

Kairo64 memungkinkan Anda memainkan game C64 milik Anda sendiri di Android. Tambahkan image disk, kaset, program, atau cartridge Anda, pilih game dari pustaka, lalu mainkan dengan gamepad atau kontrol di layar, termasuk keyboard C64. Di handheld dua layar, game dan kontrol dapat ditampilkan di layar terpisah.

Game tidak disertakan. Sebagian besar game berjalan dengan MEGA65 Open ROMs bawaan; beberapa memerlukan firmware asli Commodore dari mesin Anda sendiri.

Anda juga dapat mengunduh aplikasi yang sama secara gratis dari GitHub Releases Kairo64. Versi Google Play memiliki fitur yang sama.

Kairo64 adalah proyek independen yang menggunakan VICE dan MEGA65 Open ROMs.
