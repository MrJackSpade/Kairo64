## Short description

Play your C64 games on Android with touch controls or a gamepad.

## Full description

Kairo64 lets you play your own C64 games on Android. Add your disk, tape, program or cartridge images, pick a game from the library, and play with a gamepad or on-screen controls, including a C64 keyboard. On a two-screen handheld, the game and controls can use separate displays.

Games aren't included. Most games run with the included MEGA65 Open ROMs; some need the original Commodore firmware from your own machine.

You can also download the same app free from Kairo64 GitHub Releases. The Play version has the same features.

Kairo64 is an independent project using VICE and the MEGA65 Open ROMs.
