# Google Play listing: German (de-DE)

- **App name:** Kairo64

## Short description

Spielen Sie Ihre C64-Spiele auf Android mit Touch-Steuerung oder Gamepad.

## Full description

Mit Kairo64 spielen Sie Ihre eigenen C64-Spiele auf Android. Fügen Sie Ihre Disketten-, Kassetten-, Programm- oder Modulabbilder hinzu, wählen Sie ein Spiel aus der Bibliothek und spielen Sie mit einem Gamepad oder der Bildschirmsteuerung, einschließlich einer C64-Tastatur. Auf einem Handheld mit zwei Bildschirmen lassen sich Spiel und Steuerung auf getrennte Displays verteilen.

Spiele sind nicht enthalten. Die meisten Spiele laufen mit den enthaltenen MEGA65 Open ROMs; einige brauchen die originale Commodore-Firmware von Ihrem eigenen Gerät.

Sie können dieselbe App auch kostenlos über die GitHub Releases von Kairo64 herunterladen. Die Version bei Google Play hat dieselben Funktionen.

Kairo64 ist ein unabhängiges Projekt auf Basis von VICE und den MEGA65 Open ROMs.
