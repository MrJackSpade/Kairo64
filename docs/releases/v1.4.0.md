# v1.4.0

The first release of Kairo64, a Commodore 64 emulator.

- Plays C64 disks, tapes, programs and cartridges (D64, G64, D71, D81, T64, TAP, PRG, P00, CRT), with tape and 1541 loads run flat out.
- Ships the free MEGA65 Open ROMs. Once you import your own C64 firmware, games start on it by default.
- Each game starts on the C64 model it needs: 103 releases named for NTSC that only run on a PAL C64 (1943: The Battle of Midway) now start on PAL.
- The D-pad is the joystick in port 2. It no longer presses the cursor keys at the same time, which the C64 read as phantom keys. The cursor keys are on the bottom-screen keyboard.
- A catalog of C64 games with MobyGames descriptions and artwork.
- Scaling anchor: Settings › Graphics pins the picture to any of nine places on the screen, separately for landscape and portrait, and each game's settings can choose its own. Pick it from a 3x3 grid.
- On a two-screen device (RG DS), the keyboard, joystick and touchpad are on the bottom screen, and the D-pad moves between the screens in the library.

Both APK variants and the Play bundle have the same features.
