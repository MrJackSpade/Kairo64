# v1.5.3

- The D-pad is the joystick in port 2 alone again: it no longer presses the cursor keys (with Shift for up and left) at the same time, which the C64 read as phantom keys (Kairo64#72). The cursor keys are on the bottom-screen keyboard.
- Every controller button sends one thing per press, in every game's default controls.

Install over v1.5.2 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
