# v1.4.8

- Library: a tap on a game opens it even while the library is still updating, a list scrolled by touch stays where you left it, and every game the catalog knows shows its catalog name after a scan.
- Disks page: a disk a game's set adds can be switched on again after switching it off.
- The D-pad's default is the cursor keys and the joystick, as in the other Kairo apps; it had the joystick alone.
- CMD HD hard disk: what a game writes stays, and a save state loads with its hard disk.
- A save during a disk load, or while the drive is busy, completes.
- The 1351 mouse follows the position you give it.
- Startup commands wait for BASIC's READY. prompt.
- A Bluetooth or USB mouse moves the game's mouse directly and its buttons click in the game; the pointer comes back for the menus. Controls > Mouse > Speed sets how fast it moves.
- With a Bluetooth or USB keyboard connected, a tap on the game no longer opens the on-screen keyboard; the menu still opens it.
- A disk choice names disks that would look alike, such as one image unpacked from a ZIP and from a 7z, by their paths.

Install over v1.4.7 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
