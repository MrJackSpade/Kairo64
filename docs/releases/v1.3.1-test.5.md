# v1.3.1-test.5

Test build of Kairo64, for Commodore 64 games. It is not published to Google Play.

- The first catalog: titles and artwork from LaunchBox for 14,857 C64 games, with both copies of a game from different collections found as one game. Descriptions come later.
- Games start on Android: VICE kept its own files in a folder the app cannot write to, so every game ended at once.
- A game set to the 1541 drive after a game on the virtual drive finds its drive, where it showed "?DEVICE NOT PRESENT" or froze.
- Tapes load on the Open ROMs.
- The controller follows every Kairo app: the D-pad is both the joystick and the cursor keys, A and B are Return and Space, and X and L1 are fire.
- Startup commands and other text settings can take several lines.
- A long setting value is shortened on its row instead of the setting's name.
