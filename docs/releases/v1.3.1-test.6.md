# v1.3.1-test.6

Test build of Kairo64, for Commodore 64 games. It is not published to Google Play.

- Sound is quicker to make, so the RG DS runs the C64 at full speed with room to spare.
- Loading runs flat out while the tape or the disk drive's motor runs.
- The catalog adds MobyGames: covers and screenshots where LaunchBox has none, and many more games.
- Descriptions for thousands more C64 games.
- Many more games start on the player's firmware, and games whose disk starts another file than its first name it as a game setting.
- Joystick up in port 2 no longer also reads as down.
- A game after a loaded state starts on its own firmware.
- A game file opened from another app, such as a frontend like Neostation, opens as the library game with the same content, with that game's saves and settings.
- Games the library has already read are never hashed again; the scan shows its progress on one line.
- Disk choices list the game's own disks first, then Other.
- Updating the catalog no longer holds up the screen.
- On two screens, both come back after Home, and swapping them no longer stops the app.
