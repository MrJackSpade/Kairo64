# v1.3.1-test.4

The first test build of Kairo64, for Commodore 64 games. It is not published to Google Play.

- Runs C64 disks (D64, G64, D71, D81), tapes (T64, TAP), programs (PRG, P00) and cartridges (CRT).
- Games start on the MEGA65 Open ROMs and a virtual drive, which come with the app. A game can be set to your own C64 firmware or to an emulated 1541 drive, for games that need them.
- Machine settings for the model (PAL, NTSC, C64C and others) and what is in the control ports: a joystick in port 2 or 1, or the 1351 mouse.
- A game library from a folder of your games; archives are read in place. This build has no catalog yet, so games show by their file names, without descriptions or artwork.
- Controller, touch and on-screen keyboard controls, with a button mapping for every game.
- Save states, and per-game settings that override the all-games ones.

Games are not supplied. Import your C64 KERNAL, BASIC, character and 1541 ROMs in **Menu › Machine**. Both APK variants have the same features.
